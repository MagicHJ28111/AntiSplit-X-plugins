# AntiSplit-X Plugins

Official plugin catalog for [AntiSplit-X](https://github.com/Hiaashuu/AntiSplit-X).

## How to install

1. Open AntiSplit-X
2. Go to **Plugins** tab
3. Tap **Browse Online**
4. Choose a plugin and tap **Install**

## Contributing

Create a PR with a new `.json` file in `plugins/` and add an entry to `catalog.json`.
